# AI Core Operating Protocol v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a locally verified v2.0.0-rc1 cross-runtime release candidate with canonical Agent Skill, deterministic routing benchmark, adapters, installers, docs, CI, and release artifacts.

**Architecture:** One canonical Agent Skill is copied into runtime-specific packages by deterministic build tooling. A small Python reference router scores metadata only and powers golden routing tests; host runtimes remain responsible for actual model-driven skill activation.

**Tech Stack:** Agent Skills (`SKILL.md`), Python 3 stdlib, pytest, JSON, shell/PowerShell wrappers, GitHub Actions YAML.

**Spec:** `docs/superpowers/specs/2026-08-31-ai-core-v2-design.md`

## Global Constraints
- Single source of truth for core skill behavior.
- Metadata-first progressive disclosure.
- Bootstrap target <= 200 words.
- Minimum capability set; no fabricated tools.
- Permission systems are never bypassed.
- At least 100 golden routing scenarios.
- No GitHub publication in this phase.
