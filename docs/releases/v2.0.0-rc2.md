# AI Core Operating Protocol v2.0.0-rc2

Prerelease notes prepared for GitHub. Publication and remote CI are separate from local validation.

## What this release contains

One vendor-neutral operating skill with metadata-first capability selection, scoped execution
and evidence-based completion. Eight filesystem adapter targets: Codex, Claude Code, Gemini CLI,
Antigravity IDE, Cursor, Copilot, OpenCode and a limited generic Agent Skills layout.

Fourteen separate ZIPs cover standalone skill, Claude custom upload, OpenAI/Claude Code plugins,
marketplace, filesystem layouts and full source with technical specification. Every archive
contains the original MIT notice; SHA256SUMS.txt accompanies the assets.

## Changes

- Safe lifecycle ownership, hashes, retained snapshots, explicit plan/install/verify/rollback.
- Controlled rejection of corrupted rollback records, missing disks and cross-filesystem state.
- Mixed domain/source routing with unavailable/disabled/explicit-only handling.
- Strict benchmark inputs and deterministic registry identity handling.
- Source-pure reproducible packaging, LF metadata and stale-generated-file detection.
- English README, Uzbek guide, installation/recovery documentation and independent audit report.

## Validation

118 local tests passed on Windows / Python 3.12.13 after the independent audit corrections.
The 120-case golden and 22-case development holdout evaluate only the offline reference router.
Independent reviewers rechecked installer, router and packaging findings. See
docs/INDEPENDENT-AUDIT.md in the source/repository for evidence and limitations.

## Known limits

- No native web/mobile or other host automatic activation has been certified.
- Local installation does not synchronize into a ChatGPT/Claude cloud account.
- The reference catalog contains test metadata, not installed connectors or thousands of skills.
- Destination and lifecycle state must be on the same filesystem.
- Abrupt-kill recovery requires manual review; host permissions and consent are retained.
- Linux/macOS/Python 3.13 and remote CI status must be checked in GitHub Actions, not inferred.
- This is a prerelease, not a stable/all-hosts-supported release.

## Choose the right asset

Use *-skill-* for a compatible standalone skill importer, *-claude-upload-* for Claude custom
skills, *-openai-* for an OpenAI plugin importer, and *-claude-plugin-* for Claude Code plugins.
Use a runtime-named ZIP for that filesystem layout. Developers should use *-source-*.
Do not install all variants together; that can create duplicate discovery.

Keep the same runtime/scope/workspace/home/state context for lifecycle operations.
Read docs/install.md before migration; never use the older RC1 manifest-driven uninstaller.
