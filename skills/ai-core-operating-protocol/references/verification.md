# Verification Before Completion

Do not claim “done”, “fixed”, “working”, “deployed”, “published”, or “tests pass” without recent supporting evidence when evidence is available.

- File work: exact artifact exists and validates/opens using the available validator.
- Code: relevant tests/checks pass after the change.
- Research: material claims are supported by suitable sources.
- External write: inspect the resulting object/state, not merely request submission.
- Calculations: recompute or cross-check critical totals/units.

If verification is impossible, state exactly what was verified and what remains unverified.
