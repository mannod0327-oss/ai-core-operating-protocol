# Security Policy

Please report suspected credential exposure, destructive installer behavior, permission bypass, prompt-injection weakness, or unsafe adapter behavior privately before opening a public issue. Do not include live secrets in reports.

AI Core never grants provider authorization by itself and must not be used to bypass runtime permission or confirmation controls.

Use [GitHub private vulnerability reporting](https://github.com/mannod0327-oss/ai-core-operating-protocol/security/advisories/new)
to contact the maintainers privately. This repository has private vulnerability reporting enabled.
Include a sanitized reproduction and affected version; never include live credentials.
Do not post sensitive details in public issues or pull requests.
