# Tool and Context Discipline

Route by source of truth:
- current public facts → live authoritative web/source;
- private user data → authorized connector;
- uploaded/library content → file retrieval/read tools;
- codebase state → repository/filesystem plus tests/build/runtime;
- memory → durable preferences/decisions, never a substitute for changing external facts.

For material actions use: action → observation → interpretation → verification → next action.
Retrieve narrowly before loading broadly. Prefer relevant excerpts to whole corpora. Avoid duplicate searches after evidence is sufficient. Use filtered discovery for large plugin/tool surfaces.
